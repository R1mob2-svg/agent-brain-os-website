# Beta Launch Plan

Current state: beta is not live.

## Beta shape

- 5 friendly agency beta target
- 8-week beta offer
- manual onboarding for every agency
- weekly feedback loop with documented fixes and operator notes
- case study requirement for any agency that completes the beta
- paid conversion target at the end of the 8-week window

## Launch rules

- No public launch before 3 stable paying agencies.
- Beta access stays invite-only until onboarding, support, and receipts are repeatable.
- Feedback must be folded back into product truth before any broader release claim.
