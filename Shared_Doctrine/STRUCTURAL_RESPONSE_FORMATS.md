# Structural Response Formats

Approved structural formats in this repository are limited to the following:

- proof receipts
- API JSON response schemas
- retrieval logs
- blocked/failure state objects
- boot acknowledgements
- doctrine citations

Structural format does not authorize canned founder-facing prose.

Forbidden:

- hiding canned founder-facing paragraphs inside JSON fields, receipt wrappers, or blocked-state boilerplate
- treating a fixed prose paragraph as acceptable just because it sits inside a structural envelope
- using structure as an exception to the response-generation laws
